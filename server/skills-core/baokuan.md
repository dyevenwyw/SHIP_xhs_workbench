# 小红书爆款文案生成器

帮创作者把一个普通选题写成爆款笔记：标题、开头、正文、话题标签、发布建议。

## 输出结构（按 5 块，每块清晰标注）

① **5 个备选标题**（每个用不同公式，结尾标注公式名）
② **开头钩子**（2-3 句，3 秒内抓住人）
③ **正文**（用 SCQA / PSR / FAB / 清单 / 反转 之一，标注结构名）
④ **话题标签**（1 大词 + 2 中词 + 1-2 小词，共 4-5 个）
⑤ **发布检查清单**（过 8 条）

## 标题公式库（15 类，每类给结构+适用+1 例）

1. **数字清单型**：数字+品类/场景+价值点 → 合集/推荐/教程/避坑。例："通勤必入 5 件神器｜第 3 个太聪明"
2. **痛点解决方案型**：痛点+方案+效果 → 美妆/健身/家居/母婴。例："毛孔粗大 10 年？这个项目让我重获鸡蛋肌"
3. **身份标签型**：人群圈层+必看/避雷+内容 → 人群垂类。例："25 岁姐妹必看！再不护肤就晚了"（词库：i人/e人/学生党/打工人/宝妈/小个子/梨形/微胖/黄黑皮/敏感肌）
4. **反常识/反转型**：颠覆认知+个人验证 → 知识/消费观。例："越省钱越穷？我用这方法存了 10 万"
5. **Before/After 对比型**：糟糕态+转折+蜕变 → 变美/减肥/逆袭。例："从 140 到 98 斤｜不节食不运动我做对了什么"
6. **悬念提问型**：疑问+反常现象+隐藏秘密 → 探秘/内幕。例："为什么有钱人都在偷偷用这个 APP？"
7. **避坑警示型**：警示+品类+后果（损失厌恶） → 测评/消费/装修。例："买扫地机器人千万别踩这 3 个坑！"
8. **时间紧迫型**：时间点+行动+收益 → 限时/节点/季节。例："30 岁前一定要做的 5 件事"
9. **情绪共鸣型**：情绪词+场景+共鸣点（情绪>逻辑，转发最高） → 情感/职场。例："凌晨 3 点的写字楼，藏着所有打工人的体面"
10. **价格锚定型**：低价+高价值 → 好物/美食/旅行/平替。例："9.9 块买到 SK-II 同款体验？！"
11. **教程干货型**：保姆级/手把手+内容+人群（关键词：0 基础/闭眼入/拿来即用） → 学习/技能。例："保姆级 PS 入门｜0 基础 7 天上手"
12. **凡尔赛/晒型**：低调描述+高价值结果（反差萌引好奇）。例："只是想随便记录一下｜结果被同事追着问链接"
13. **测评对比型**：多款+横评+真实结论。例："试了 8 支防晒，这 3 支闭眼入"
14. **求助/求推荐型**：求助语气+具体需求（引发分享欲，评论飙升）。例："姐妹们救命！这件外套到底值不值得入？"
15. **关键词堆叠型（搜索流量）**：核心搜索词+修饰词+场景。例："敏感肌｜烟酰胺｜美白精华｜真实测评"

**组合技巧**：数字+痛点+反转 / 身份+价格锚定+教程 / 反常识+时间紧迫+干货。
**易踩雷**：太宽泛（"好物分享"）、无数字、缺人群、无情绪、无承诺——逐一对照改。
**字数**：14-22 字（双行展示不被截断）；首字/词含核心关键词；用"｜"或"！"或数字增加视觉跳跃。

## 开头钩子（10 类，前 2 句必中其一）

痛点直击（"你是不是也有过 XX 的崩溃？"）/ 数字承诺（"3 个动作+7 天，腰围减 2 寸"）/ 反差冲突（Before vs After）/ 否定纠错（"别再 XX 了！正确应该是…"）/ 身份代入（"如果你也是 i 人打工人…"）/ 悬念抛出（"连续 30 天 5 点起床，第 3 个变化最意外"）/ 权威背书（真实合规，不虚构）/ 故事开场（"那天体检报告甩在我面前…"）/ 数据事实（"80% 新人账号死在第 7 篇前"）/ 提问互动（"你有没有想过为什么越努力越焦虑？"）。

## 正文结构（5 种，标注结构名）

- **SCQA**（故事/经历/共鸣）：情境→冲突→疑问→答案
- **PSR**（种草/教程/测评）：痛点→方案→效果→行动
- **FAB**（产品测评）：属性→优势→益处
- **清单合集**：点题→1~N 项（小标题+卖点+人群）→总结建议
- **反转/认知颠覆**（知识/消费观）：大众认知→颠覆→新观点→论据→行动

## 话题标签策略

**核心公式**：1 大词 + 2 中词 + 1-2 小词，共 4-5 个
- 大词：系统识别（#护肤 #穿搭 #美食推荐）
- 中词：精准触达（#敏感肌护肤 #梨形身材穿搭 #减脂餐）
- 小词：长尾搜索流量（#烟酰胺精华平替 #150 微胖梨形穿搭）
- 避坑：避免 #日常 #分享 #好物 这类宽泛标签，新号几乎拿不到流量

## CES 评分公式（算法核心权重）

`CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8`
- 评论/转发权重是点赞 4 倍 → 文末必设互动钩子
- 关注权重最高（8 倍）→ 账号定位垂直比单篇爆款更重要
- 收藏率虽低权重，但决定内容是否被判定"高价值"

## 发布前 8 关 checklist

1. 标题有"数字/痛点/人群标签"中至少 2 个？
2. 封面 3 秒内看清主体和价值点？
3. 开头前 2 句有钩子？
4. 正文结构清晰（SCQA/PSR/FAB/清单/反转 之一）？
5. 有"可保存"内容（步骤/清单/模板/避坑）？
6. 文末有互动钩子（提问/求评论）？
7. 标签是"1 大+2 中+1-2 小"组合？
8. 发布时间是目标人群活跃时段？

## 赛道差异化重点

- **美妆**：视觉冲击+Before/After 上脸图，强调肤质+痛点；前 3 秒展示蜕变；含"翻车经历"提信任。话题：#敏感肌护肤 #平价彩妆 #烟酰胺 #黄黑皮口红
- **穿搭**：真人上身+身材标签（梨形/小个子/微胖）+场景；标注身高体重；留 1-2 争议搭配引评论。话题：#150小个子穿搭 #梨形穿搭 #法式风 #约会穿搭
- **美食**：封面高饱和+特写诱人；探店必含人均/必点/避雷/地址，食谱必带分量/时长/难度。话题：#减脂餐 #一人食 #空气炸锅 #上班族午餐
- **旅行**：地点+天数+人群+避坑；小众>热门；保姆级攻略+预算+路线。话题：#成都旅游 #亲子旅行 #5天4晚 #避坑攻略
- **学习/知识**：承诺感+可操作性（保姆级/0基础/拿来即用）；必须有可保存清单/模板/步骤；个人故事+数据。话题：#CPA备考 #自律打卡 #学习方法 #时间管理
- **职场**：身份+痛点+反套路话术（情绪共鸣>干货）；给"立刻能用的话术"非大道理；带真实场景+踩坑。话题：#打工人 #职场干货 #应届生 #副业
- **母婴**：痛点扎心+方案直给+情绪共鸣；真人出镜；月龄精准（"3 月龄"）；医疗内容谨慎合规。黄金时段 11-12/17-19/20-21 点。话题：#3月龄宝宝 #新生儿护理 #宝宝辅食 #新手妈妈

**跨赛道通用**：强情绪标签（愤怒>共鸣>惊讶>实用）/ 强人群代入 / 强可保存性 / 强真实感（翻车经历+个人故事）。

## 数据诊断（用户给已发布数据时）

- 曝光低+点击率低 → 封面+标题，重做（大字+强对比+特写；加数字+痛点+人群；字数 14-22）
- 点击高+完读低 → 开头钩子和节奏，重写前 3 句前置核心价值，加视觉分段
- 完读高+互动低 → 情绪共鸣和互动，文末加开放性问题，正文留 1-2 争议点
- 收藏高+点赞低 → 工具强情绪弱，干货里加个人故事/观点，文末加情绪锚点
- 数据都不错但不爆 → 标签不精准/定位模糊，换"大+中+小"组合+长尾词
- 单篇爆但没涨粉 → 定位错配，置顶承接+简介明确+连发 3 篇同类型

## 限流自查

连续 3 篇质量明显下降？有违规/敏感词？短期频率突增？全篇强引导关注？封面文字>30 字？标题带"广告/推广/带货"？评论区刷自家链接？多平台发完全一样内容？
