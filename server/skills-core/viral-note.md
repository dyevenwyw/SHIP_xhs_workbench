# 小红书爆款文案生成器

一个把"产品/话题 + 卖点 + 人群"转换成可直接发布的小红书笔记文案的工作流：5 个不同角度的标题候选、一段口语化正文、一组标签。

## 需要向用户收集的信息

开始生成前，尽量确认以下信息（缺了就合理推断，不要反复追问）：

1. **产品/话题**（必需）——这篇笔记写什么
2. **核心卖点/亮点**（可选）——2-5 条，没有就基于话题合理发挥
3. **目标人群**（可选）——没有就从话题推断，比如"学生党好物"默认是大学生
4. **文案风格**（可选，默认"种草安利"）——从以下五种里选一个：
   - 种草安利：主推"值得买/太好用了"的安利语气
   - 干货教程：分步骤讲清楚怎么做
   - 情绪共鸣：从一个具体场景/情绪切入，产品是解决方案
   - 开箱测评：强调第一印象、上手体验、优缺点
   - 好物清单：多个物品/方法罗列式盘点

## 生成规则

### 标题（5 个，每个走不同角度）

给出 5 个标题候选，分别对应：

1. **悬念式**——留一个信息缺口，让人想点进来看（如"这个东西我居然瞒了闺蜜半年"）
2. **数字式**——用具体数字增加可信度（如"3 个技巧/花了 200 块测出的真相"）
3. **反差式**——制造预期落差（如"没想到最好用的居然是最便宜的"）
4. **情绪共鸣式**——直接说出读者的心声（如"谁懂啊，终于找到了"）
5. **口语化安利式**——像跟朋友聊天一样直接推荐（如"姐妹们冲，这个是真的绝"）

每个标题控制在 12-20 字以内，可以带 emoji 但不要堆砌（1 个足够），读起来必须像真人写的，不能有明显 AI 腔调（比如不要用"探索""赋能""解锁"这类词）。

### 正文（200-350 字）

结构：
- **开头（1-2 句）**：3 秒抓住注意力，可以是提问、场景代入或者反常识的一句话，不要用"大家好/今天给大家分享"这种开场白
- **中段**：用 emoji 分点列出卖点/步骤/细节，每点信息密度要够，别写空话
- **结尾（1 句）**：自然引导互动——提问、求收藏、求关注，不要生硬地喊"记得点赞关注"

语气要求：口语化、有具体细节（数字、场景、感受），少用感叹号，不要出现"总而言之""综上所述"这类书面语连接词。

### 标签（6-8 个）

不带 # 号，混合以下两类：
- **大词**：话题所在的大类目（如"学生党好物""职场穿搭"）
- **细分词**：更精准的长尾词（如"平价通勤包推荐""开学好物清单"）


## 约束

- 如果用户要连续产出多篇（比如"帮我写 5 篇不同角度的笔记"），确保每篇的切入点、句式、开头写法都明显不同，避免同质化
- 不编造具体的数据/资质/功效（比如"通过 XX 认证""临床验证"），如果用户没提供依据，就用主观体验的表达方式（"我自己用下来觉得……"）而不是断言事实
